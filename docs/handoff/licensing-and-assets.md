# Licensing, assets and third-party material

The project has no selected licence for its own source code in this snapshot. Do not infer an MIT/open-source grant from the dependencies' licences or from receiving a technical handoff. Rafa should choose redistribution terms before making the repository public or commissioning third-party reuse. This document records the current state; it is not a legal rights opinion.

Direct dependencies are React, React DOM, React Flow, Lucide React and Vite. The generated `docs/reference/dependencies.json` records all lockfile package versions and declared licences, including optional platform packages. `THIRD_PARTY_NOTICES.md` includes licence/notice text found in installed dependency packages; optional packages not present locally are recorded in the inventory and must be checked if redistributed in another build.

Built application assets contain bundled portions of dependencies. Preserve applicable copyright/licence notices when distributing a build. Dependency licenses do not cover the user's imported graphics or third-party art. The archive does not intentionally include user art outside the separately exported personal studies.

SVG/image uploads are embedded into graphs after sanitization/conversion. Their copyright origin cannot be inferred from data URIs/path points. The product owner must confirm rights for commercial/public use. Do not publish personal study backups automatically with source code.

The Cavalry/Houdini links in the historical research note are design references. Their software, documentation and trademarks are not licensed into this implementation by those links. This handoff paraphrases the app's design decisions; it does not package copies of those products or whole documentation sites.
